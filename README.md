# Cat Chase

A 3D browser game made with three.js. You play as a cat and have 60 seconds to catch as many mice as you can.

## ▶ Play

**https://willa15.github.io/cat-mouse-game/**

You can also download `index.html` and double-click it. You need an internet connection the first time so three.js can load.

## How to play

| Action | Keys |
| --- | --- |
| Move | WASD or arrow keys (press two at once to move diagonally) |
| Jump | Space |
| Start / play again | Space or the on-screen buttons |

- You catch a mouse by touching it, and each catch is worth 1 point.
- The round ends when the timer reaches 0.
- Obstacles are low enough to jump onto. Hop over them to cut across while the mice have to run around.

## Cats and levels

Pick your cat and level from the main menu:

- **Cats:** Ginger, Shadow, Siamese
- **Levels:** Beach, Garden, City Streets
